# Contributing

Good contributions correct citations or legitimate source links, improve metadata, add evidence limitations or historical caveats, add author-created shareable resources, add verified jurisdiction-specific resources, or improve accessibility and search.

Do not contribute PHI, client-specific examples, copyrighted full text without permission, restricted test content, proprietary scoring material, or unofficial commercial assessment copies.

When uncertain, add metadata and link to the legitimate source rather than uploading the protected source file.
