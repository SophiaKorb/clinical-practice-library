# Ingestion guide

1. Identify the exact resource, version, year, source, and legitimate source URL.
2. Choose one primary section. Add secondary concepts as tags instead of duplicate records.
3. Record audience and purpose.
4. Distinguish public domain, freely available but copyrighted, purchased or restricted, scoring-service access, and unknown access.
5. Add limitations for historical classics, emerging evidence, and screening tools that can be overinterpreted.
6. Link to protected material rather than uploading it.
7. Never add PHI, client identifiers, completed forms, or scored protocols.
8. Give jurisdiction-specific material a last-verified date.
9. Prefer one canonical record.
10. Update the source record instead of creating parallel lists.

## Research-core rule

The 95-item research core is intentionally capped. A paper can be useful without belonging in the core.

## Assessment rule

A located file does not establish permission to use it. Administration, copying, scoring, qualification, and telehealth rights are separate questions.

## Mature-record fields

Add last verified, evidence version, owner or reviewer, review cadence, and change log as the library develops.
