# Public site / private source model

The Clinical Practice Library intentionally separates source from publication.

- **Private repository:** source, working metadata, maintenance files, and future admin tooling.
- **Public website:** only resources intentionally approved for public use.
- **Barrier → Support guides:** author-created public-facing materials presented as interactive web editions.
- **No PHI or restricted assessment content:** neither belongs in the public build.

The web editions include interactive checkboxes and note fields saved locally in the visitor's browser. They do not send entered information to the repository or a server.
