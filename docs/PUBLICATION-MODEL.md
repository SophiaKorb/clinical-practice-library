# CPL publication, public-repository, and privacy boundary

**Verified November 11, 2026:** `SophiaKorb/clinical-practice-library` is a **public GitHub repository**. The previous description of a private repository was incorrect. This document changes no permissions or deployment settings.

- **Public GitHub source:** Files committed to this repository, including draft branches and pull requests, can be read by other people. Do not commit materials unsuitable for public access.
- **Website publication:** Being in `main`, a preview build, an inventory, or a passing CI run does not grant clinical, accessibility, rights, or publication approval. Each requires its own review and owner authorization.
- **Draft materials:** Keep editorial status, evidence limitations, attribution, and rights explicit. Draft clinical content is not approved guidance.
- **Prohibited content:** Never commit PHI, identifiable client examples, completed or scored protocols, restricted test items, proprietary scoring content, or copyrighted full-text documents without redistribution rights.
- **Barrier → Support guides:** Educational, author-created supports; not diagnostic instruments or permission to administer restricted procedures.

## Interactive-data privacy

Some worksheets and site interactions have editable fields or browser-local state. Do not assume entered information is transient or confidential; it may persist on shared devices, be exposed by browser extensions, or appear in printed or downloaded copies. Avoid entering identifiable client information in public educational resources. Statements that a specific route transmits no data must be verified against that route's actual implementation, rather than inferred from static hosting.

This is documentation, not a technical privacy certification or a permission change.
