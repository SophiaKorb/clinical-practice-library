## Regenerate the PDFs

Serve the repository locally on port 8765. Use Node with Playwright, Python with ReportLab and pypdf, and a compatible Chrome installation. The script uses US Letter print styling and adds native fields while preserving the form tree.

```sh
CPL_BROWSER_EXECUTABLE=/path/to/chrome node scripts/render-visual-worksheets.cjs
```

`CPL_PREVIEW_ORIGIN` overrides the local origin. `CODEX_PRIMARY_RUNTIME_NODE_MODULES` and `CODEX_PRIMARY_RUNTIME_PYTHON` are supported when running in ChatGPT Work. After changing worksheet layout, regenerate all three PDFs, check that each remains two pages, and render both pages for review. Keep public PDFs blank.
