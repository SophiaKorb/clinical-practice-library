# CPL Phase 8B — Reorganize by decisions, not shelf names

Status: **new decision-first entry implemented; comprehensive consolidation and user testing remain open**. The old directory and 150 generated topic resources are preserved. Branch: `cpl-2-colorful-helpful`, never `main`.

## Organizational rationale
The prior main navigation mixed diagnoses, presenting problems, treatment methods, resource formats, audiences and places at the same hierarchy. This made “What should I do now?” ambiguous and generated repeat entry routes. Replacing it with another diagnosis hierarchy would not solve the problem.

## Primary access
1. **Understand / assess:** What is being observed? Which explanations remain? What evidence and response access would change the formulation?
2. **Plan / intervene:** What must be addressed safely? What treatment, care coordination or adaptation fits? What happened when tried?
3. **Practice / communicate:** What real spatial, choice, supported-language or printable tool enables participation?

These are **parallel entry intents, not fixed steps**. The clinical action loop (formulate, choose, try, review) explicitly returns to formulation; safety and communication access apply everywhere.

## Secondary facets, not competing top-level shelves
- Clinical presentation/diagnostic category.
- Function and clinical task.
- Age/development and environment.
- Audience: clinician, family, caregiver, trainee, case manager or school.
- Format: clinician guide, assessment decision, interactive case, functional map, supported-choice tool, handout or printable.
- Provenance and readiness: authoritative primary, original teaching heuristic, qualified review pending and language/access limitations.

The finder remains the cross-cutting search/filter interface. `resources/index.html` remains the **Complete directory**, not the primary clinical path. Source URLs and detailed content are not removed.

## UI and accessibility
- Phone landing route is a short three-door set, not a nested subject taxonomy; SVG symbols represent investigate, act and use practical tools.
- The four-stage clinical cycle retains visible arrows on phones and has a feedback return rather than implying a one-way checklist.
- Mobile top navigation prioritizes Start, Find and More; secondary destinations are within native disclosure.
- The flagship visual toolkit's avoidance cycle remains 2×2 with actual connectors and the skill/access matrix stays two-dimensional at narrow widths.
- Accessibility and comprehension on real phones, screen readers, and prints require user QA. Do not infer usability from source checks.

## Remaining reorganization work
Make authoritative starting points in each specialty, remove redundant *entry paths* without deleting useful resources, improve facet coverage and tags, eliminate outdated duplicated explanations, and link each clinical problem directly to the best next decision or tool. The new route page is a working IA candidate, not a claim that all 467 pages have been editorially reorganized.
