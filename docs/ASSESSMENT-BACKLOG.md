# Assessment verification backlog

This backlog tracks clinically important tools or families that need current access, version, or workflow verification. It deliberately excludes local filenames and any client-specific information.

- **Vanderbilt ADHD scales** (ADHD): Find legitimate current forms and scoring instructions Priority: High.
- **Conners scales** (ADHD/executive functioning): Clarify access to Conners 4 vs older versions Priority: High.
- **C-SSRS** (Suicide/self-harm): Verify clinic-approved version, training, and documentation workflow Priority: Critical.
- **ASQ Suicide Screening Tool** (Suicide/self-harm): Verify clinic workflow and disposition pathway Priority: Critical.
- **PCL-5** (PTSD): Locate official VA copy and scoring guidance Priority: High.
- **CPSS-5 / CATS** (Child trauma/PTSD): Compare feasibility, age/language coverage, and access Priority: High.
- **CY-BOCS / Y-BOCS** (OCD): Verify training, forms, copyright, and child/adult versions Priority: High.
- **SCARED** (Child anxiety): Locate official/authorized forms and current interpretation guidance Priority: High.
- **RCADS** (Child anxiety/depression): Verify access, scoring, norms, languages, and electronic use Priority: High.
- **PROMIS Pediatric Anxiety** (Anxiety): Inventory exact form, short form, T-score conversion, and HealthMeasures terms Priority: Medium.
- **PHQ-A** (Adolescent depression): Locate official form and suicide follow-up workflow Priority: High.
- **CALOCUS-CASII** (Level of care/function): Locate current manual, anchors, training, and permitted use Priority: High.
- **ADOS-2** (Autism): Record training, kit, scope, telehealth limits, and access Priority: High.
- **ADI-R** (Autism/developmental history): Record qualification, time, materials, and role in battery Priority: Medium.
- **Social Responsiveness Scale, 2nd ed.** (Autism/social functioning): Verify SRS-2 access and appropriate interpretive cautions Priority: Medium.
- **BRIEF2 / BRIEF-A** (Executive functioning): Clarify versions and purchased access Priority: Medium.
- **WISC-V / WAIS-5** (Cognitive ability): Record qualification, current access, referral triggers; never store items Priority: High.
- **WIAT-4 / WJ V Tests of Achievement** (Academic achievement): Record access, qualification, battery choices, and referral pathway Priority: High.
- **CTOPP-2 / GORT-5 / TOWRE-2** (Reading processes): Build construct map; verify access and age ranges Priority: Medium.
- **KeyMath-3 / WIAT Math / WJ Math** (Mathematics): Build math domain map before selecting tests Priority: Medium.
- **Faux Pas Test / Strange Stories / NEPSY-II Social Perception** (Social cognition): Separate standardized tools from informal probes; audit developmental validity Priority: Medium.

## Cross-cutting work

- Verify legitimate access and qualification requirements separately from possession.
- Verify remote-administration permissions separately from technical feasibility.
- Add validated Spanish versions only when equivalence and scoring are supported.
- Keep suicide-risk tools tied to clinic-approved disposition and documentation workflows.
- Keep autism, ADHD, trauma, and learning pathways multi-method and multi-informant where indicated.
- Add last-verified dates and review cadence as records mature.
