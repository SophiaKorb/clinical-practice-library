# CPL nine-page universal symbol review — QA checkpoint, 25 Oct 2026

**Scope:** only the new stand-alone nine-page CPL functional visual-access review set. Current public CPL, its original 17 tools, and other project branches remain unchanged.

## Design changes
- Used the *user-provided October 25 illustration sheet* as the visual-semantic vocabulary: speech/pictures, time, break, move, help, school/home/doctor, and familiar activity objects.
- At print sizes, literal screenshot crops looked like illegible dots. Rebuilt those same simple motifs as **scalable black-line SVGs** instead. The six approved detailed scenes remain intact where scene context adds meaning.
- Universal YES is a checkmark; NO is an X; NOT SURE is a question mark. These three remain **distinct from STOP** (octagon) and BREAK (pause bars). The reference sheet includes a check and question mark; the X is a conventional companion symbol, not an asserted exact original screenshot graphic.
- Differentiated REPEAT THE MESSAGE from USE DIFFERENT WORDS: one speech bubble with repeat arrow vs overlapping speech bubbles. Neither uses the CHANGE BOARD's routine-change icon.
- Removed circular-change icons from ANOTHER WAY/ANOTHER IDEA when the drawing could imply a change in routine rather than a novel idea.
- Shared school and home drawings recur unchanged across both rows of the Usually/Today change board.
- Kept the original CPL labels and clinical cautions; this is not an AAC system or a validated consent/capacity assessment.

## QA
- Nine actual US Letter PDF pages; each has selectable text, original source-tool footer, no out-of-bounds words, no extra blank pages.
- Five person-facing assent options remain: YES, NO, NOT SURE, BREAK, STOP, each visibly distinct.
- Text-first where a concept resists clear iconography. The change board remains a supplementary example and is not a one-to-one replacement for a CPL original.
- Checked the full contact sheet and enlarged pages 1, 3, 4, 5 and 9.
