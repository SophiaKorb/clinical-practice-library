School Access Toolkit · Clinical

ADHD
Barrier → Support

Created by Sophia Cohon, PhD

Clinical version for functional formulation, differential questions, implementable plan wording, and implementation review. Barrier numbers and support codes match the Plain Language version.

Clinical and educational formulation

  • Define the barrier in a specific task, setting, and demand.
  • Generate competing hypotheses instead of relying on diagnosis alone.
  • Compare conditions, supports, settings, and response formats.
  • Separate access supports from instruction for missing skills.
  • Operationalize who, where, when, how often, and how success will be reviewed.

Barrier 1

Directions do not become action

Observable presentation: Starts the wrong task, misses steps, or understands better one-to-one.

1-ACue before an important direction. Staff use the student’s private cue, then give the direction.
1-BMake directions visible. Pair spoken directions with written, picture, or modeled directions.
1-CLimit and number steps. Give one step at a time or a short numbered sequence.
1-DCheck the first step. Ask the student to state or show the first action before beginning.
1-EProvide essential notes. Give an outline, guided notes, or teacher copy of key notes.
Consider

Receptive language, processing speed, hearing, overload, and instruction length can look like inattention.

Data to review

Compare one-step vs multistep directions, oral vs visual directions, and settings with different distraction levels.

Avoid assuming / implementation note

Do not infer refusal from missed directions. Test whether reducing verbal load changes performance.

Barrier 2

Working memory loses steps or materials

Observable presentation: Forgets later steps, assignments, materials, or submission routines.

2-AUse routine checklists. Provide checklists for start-up, pack-up, and turning in work.
2-BUse one assignment system. Post complete assignments in one named paper or digital location.
2-CSchedule organization checks. Name who checks the binder, backpack, or digital system and how often.
2-DKeep materials in fixed places. Use labeled, consistent locations and color coding.
2-EReduce copying demands. Provide written assignment information instead of relying on copying.
Consider

Separate working memory, prospective memory, organization, and material-management problems.

Data to review

Look at whether information is lost during the task, after a delay, or at transitions such as pack-up and submission.

Avoid assuming / implementation note

External memory systems should reduce memory demand rather than require the student to remember to use several systems.

Barrier 3

Task initiation and completion break down

Observable presentation: Sits without starting, abandons long work, or needs an adult beside them.

3-AShow start and finish. Mark the first action and the point at which the task is complete.
3-BChunk the task. Divide work into numbered sections with brief check-ins.
3-CUse a start prompt. Staff give the agreed private prompt within the first ___ minutes.
3-DAdd interim deadlines. Set visible checkpoints for long work and projects.
3-EUse planned work intervals. Define the work period and return point; do not make the student request each interval.
Consider

Differentiate initiation latency, sustained attention, task difficulty, perfectionism/anxiety, unclear first steps, and low reinforcement.

Data to review

Measure time to first action, amount completed after a start cue, and where work stops.

Avoid assuming / implementation note

A support should identify the first action and reduce activation cost without turning every task into adult prompting.

Barrier 4

Time and long-term planning are unreliable

Observable presentation: Underestimates time, waits for urgency, or misses project deadlines.

4-AExternalize time. Use a visual timer and written time markers.
4-BProvide a project map. List steps, materials, due dates, and who checks progress.
4-CBreak deadlines apart. Use interim due dates with recorded completion checks.
4-DSet a homework limit. Define a maximum duration and the parent response when time ends.
4-ETeach planning explicitly. Provide individualized instruction and guided practice when planning is a skill deficit.
4-FDefine home-school communication. Use one named method with a specific purpose and frequency when coordination is genuinely needed.
Consider

Consider time estimation, prospective memory, prioritization, sequencing, and delayed reinforcement.

Data to review

Review long-term projects separately from daily work. Interim deadlines and progress checks often reveal the bottleneck.

Avoid assuming / implementation note

Avoid labeling chronic lateness as motivation before checking planning and time-perception demands.

Barrier 5

Written output hides knowledge

Observable presentation: Oral explanations are stronger than written work; mechanics consume the task.

5-AOffer typing tools. Allow word processing, spell check, or word prediction.
5-BUse planning supports. Provide graphic organizers, outlines, or sentence starters.
5-CAllow alternate response. Use speech-to-text, dictation, or oral response when writing is not the target.
5-DSeparate scoring. Score content separately from mechanics when mechanics are not the target.
5-EReduce repetitive writing. Shorten repeated items after the student shows the intended skill.
Consider

Consider ADHD-related output inconsistency alongside dysgraphia, language disorder, learning disability, and motor demands.

Data to review

Compare oral knowledge, typed work, handwriting, planning support, and time-limited output.

Avoid assuming / implementation note

Use alternate response formats for access while still addressing any skill that requires instruction.

Barrier 6

Environmental load disrupts access

Observable presentation: Sound, movement, visual clutter, or crowded spaces pull attention or cause overload.

6-AUse strategic seating. Choose seating based on the identified distraction and access to instruction.
6-BProvide a defined quiet workspace. Name the tasks and location for reduced-distraction work.
6-CManage sound. Provide approved noise reduction for named activities.
6-DReduce visual clutter. Show less material at once and clear the immediate work area.
6-EProvide flexible work position. Allow standing or alternate seating when data show it improves access.
6-FVisually isolate part of a crowded page with a reading window, line guide, or paper cover.
6-GUse an accessible digital copy with zoom, highlighting, or read-aloud tools when reading itself is not the target.
6-HHighlight key words, operation signs, decimal points, or place-value information when visual scanning contributes to errors.
Consider

Distinguish distractibility from sensory overload, anxiety, visual crowding, peer distraction, and task disengagement.

Data to review

Compare performance across seating, sound, visual load, group size, and task types.

Avoid assuming / implementation note

Strategic environmental changes should be based on the actual source of interference, not a generic 'quiet room' rule.

Barrier 7

Movement, transitions, or regulation interrupt participation

Observable presentation: Waiting, changes, or long sitting lead to leaving, conflict, or loss of learning.

7-APreview transitions. Give a schedule cue and countdown before identified transitions.
7-BSchedule preventive movement. Provide movement before predictable overload, with a return routine.
7-CReduce empty waiting. Give a concrete waiting task or shorten wait time.
7-DUse a private regulation signal. Staff prompt the agreed cue without public correction.
7-ESupport high-risk settings. Name the adult and setting for arrival, lunch, passing periods, or dismissal.
7-FPrompt access to an already-approved support when the student cannot yet recognize or request it independently.
Consider

Consider hyperactivity/restlessness, transition difficulty, waiting demands, emotion regulation, and under-stimulation.

Data to review

Identify predictable antecedents and whether preventive movement or transition supports reduce disruption.

Avoid assuming / implementation note

Movement should be functional and dignified, not contingent on escalating first.

Barrier 8

Testing format distorts performance

Observable presentation: Rushing, inattention, memory load, or response format hides learned content.

8-ADefine extended time. State the amount, task types, and setting.
8-BSegment tests. Present one section at a time and record completion.
8-CUse a reduced-distraction setting. Identify the location and eligible assessments.
8-DAllow planned brief breaks. Define length, frequency, and whether time stops.
8-EUse accessible response methods. Allow answers in the booklet, typing, or oral response when the target permits.
8-FUse a math-fact sheet or multiplication table when memorized recall is not the skill being measured.
8-GShow a sample format or practice item before an assessment begins.
Consider

Separate knowledge from attention, pace, working-memory load, response format, and test environment.

Data to review

Compare classroom performance, untimed work, oral explanation, and performance across test formats.

Avoid assuming / implementation note

Testing supports should improve validity rather than inflate or lower the learning target.

Clinical documentation

Diagnosis can be relevant evidence, but it does not by itself determine IEP or Section 504 eligibility. Describe functional impairment, likely school impact, and why school-based evaluation or review is recommended.
