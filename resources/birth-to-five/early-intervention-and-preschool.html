How to use these resources

Families can raise developmental concerns and request evaluation without first obtaining a diagnosis. Use the correct age pathway, and verify state and local procedures before quoting a deadline or promising eligibility.

Practice note

Younger than 3: contact the state Part C early-intervention program. At 3 through 5: contact the local public school or district for possible Part B preschool special-education evaluation. Transition planning should begin before age 3 when a child is already receiving Part C services. Eligibility and procedural details depend on the program and state.

For other early-childhood topics, return to the Birth–5 resource collections.
