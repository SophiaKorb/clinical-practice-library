Mi mapa de transición

Un plan sencillo para terminar una cosa y comenzar la siguiente

1. AHORA

Estoy haciendo: _________________________________________

2. DESPUÉS

Voy a: ______________________________________

3. PRIMER MOVIMIENTO

Lo primero que hará mi cuerpo es:

  • Ponerme de pie
  • Guardar algo
  • Guardar mi trabajo
  • Recoger lo que necesito
  • Caminar hasta: ____________________
  • Otra cosa: ______________________________

4. AYÚDAME A SABERLO

  • Muéstrame una imagen
  • Escríbelo
  • Usa un temporizador
  • Dímelo una vez
  • Avísame más de una vez
  • Dime qué seguirá igual
  • Muéstrame el primer paso

5. AYÚDAME A PARAR

  • Déjame terminar una parte pequeña
  • Ayúdame a elegir un punto para parar
  • Toma una foto
  • Guárdalo o márcalo
  • Dime cuándo puedo volver
  • Usa nuestra señal de terminado: ______________________

6. UNA ELECCIÓN QUE PUEDO TENER

  • Cuándo parar dentro de un rango pequeño
  • Qué llevar
  • Qué ruta tomar
  • Quién viene conmigo
  • Qué primer paso usar

Mi elección: _________________________________________

7. APOYO QUE PUEDO LLEVAR

  • Audífonos
  • Objeto para mover las manos
  • Objeto de consuelo
  • Agua o algo de comer
  • Plan escrito
  • Movimiento
  • Otro: __________________________________________

8. DESPUÉS DE LLEGAR

Puede que necesite:

  • Silencio
  • Movimiento
  • Una pausa breve
  • Menos palabras
  • Ayuda para empezar
  • Tiempo para observar antes de participar
  • Otro: __________________________________________

El plan está ayudando si

____________________________________________________

Para adultos

Completa esto durante un momento de calma. Usa solo las secciones que ayuden. Una transición no es exitosa simplemente porque la persona parezca obedecer. Después, revisa seguridad, comprensión, dignidad y capacidad.
