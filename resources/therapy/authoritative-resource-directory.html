Authoritative clinical resource directory

Start with the clinical question, choose a source with the right scope, then examine its evidence and implementation requirements.

Evidence is specific to the recommendation.

A guideline label is not a universal strength rating. Guideline recommendations, practice syntheses, implementation training, and patient education serve different purposes. Emerging approaches and expert opinion need explicit uncertainty; no new approach is endorsed by this directory. Retrieval status describes access, not clinical approval.
